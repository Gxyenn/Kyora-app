## Apa ini

Kyora adalah aplikasi Android untuk menonton anime. Semua video diputar langsung di dalam
aplikasi dengan pemutar bawaan — bukan jendela browser, bukan embed.

Repository ini adalah **kanal unduhan resmi**: berkas APK diterbitkan di halaman
[Releases](../../releases) oleh pipeline build otomatis.

## Fitur

| | |
|---|---|
| Katalog | Beranda, jelajah genre & tipe, jadwal rilis, pencarian |
| Pemutar | Kontrol kaca, pilih resolusi, kecepatan, subtitle, layar penuh, mini player |
| Koleksi | Bookmark dan riwayat tontonan tersinkron ke akun |
| Komentar | Diskusi per episode, lengkap dengan balasan bertingkat |
| Unduhan | Tautan unduhan multi-server per episode |
| Tampilan | Tema gelap sinematik, animasi lembut, ikon dan maskot khas Kyora |

## Cara memasang

1. Unduh APK terbaru dari halaman [Releases](../../releases).
2. Buka berkasnya di perangkat, lalu izinkan pemasangan dari sumber ini bila diminta.
3. Kalau sebelumnya sudah ada Kyora versi lama, **hapus dulu** (tanda tangannya berbeda).

> Aplikasi juga memeriksa pembaruan secara otomatis dan menawarkan pemasangan begitu ada versi baru.

## Persyaratan

- Android 8.0 (API 26) atau lebih baru
- Akun Google untuk masuk (menyimpan koleksi & ikut berkomentar)
