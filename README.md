## Kenapa Kyora

- **Pemutar sungguhan, bukan jendela browser.** Video berjalan langsung di dalam aplikasi dengan
  kontrol kaca transparan, jadi tidak ada tampilan embed yang mengganggu.
- **Koleksi ikut akunmu.** Bookmark dan riwayat tontonan tersimpan di akun, jadi pindah perangkat
  tidak berarti mulai dari nol — dan riwayat tidak tercampur antar akun.
- **Pembaruan mandiri.** Begitu ada versi baru, Kyora menawarkannya, mengunduh sendiri, lalu
  membuka pemasang Android. Kamu tidak perlu mencari berkas APK-nya.
- **Komentar per episode.** Diskusi di bawah pemutar, satu tingkat balasan dengan garis penghubung
  supaya jelas siapa membalas siapa.

## Fitur

| | |
|---|---|
| **Beranda** | Anime populer bergiliran, chip genre, seksi pembaruan, populer, dan rekomendasi |
| **Jelajah** | Kategori, genre, tipe (TV/Movie/OVA/ONA/Special), dan alfabetis A–Z |
| **Jadwal** | Jadwal rilis Senin–Minggu dengan tab per hari |
| **Cari** | Pencarian judul plus pintasan ke genre, tipe, dan abjad |
| **Detail** | Poster blur, sinopsis, daftar episode, rail anime terkait & rekomendasi |
| **Pemutar** | Resolusi, kecepatan 0,25×–2×, subtitle, kunci layar, layar penuh, ±10 detik, mini player |
| **Unduhan** | Tautan unduhan multi-server per episode |
| **Koleksi** | Bookmark + riwayat dengan progres dan lanjut-tonton |
| **Komentar** | Diskusi per episode, balasan bertingkat, tanda admin |
| **Profil** | Nama tampilan, statistik, dan seluruh pengaturan aplikasi |

## Cara memasang

1. **Unduh** APK terbaru dari halaman [Releases](../../releases/latest).
2. Buka berkasnya di perangkat, lalu **izinkan pemasangan dari sumber ini** bila diminta.
   (Android menanyakan ini sekali; tanpa itu pemasangan tidak bisa dilanjutkan.)
3. Kalau sebelumnya sudah ada Kyora versi lama, **hapus dulu** — tanda tangan APK-nya berbeda.

Setelah terpasang, pembaruan berikutnya **tidak perlu lagi** dilakukan manual:

> Kyora memeriksa versi terbaru saat dibuka, menampilkan popup pembaruan, mengunduh APK-nya sendiri,
> lalu membuka pemasang paket Android. Cukup tekan **Pasang**.

## Pertanyaan yang sering muncul

**Kenapa saat memasang muncul peringatan "sumber tidak dikenal"?**
Karena APK ini tidak diunduh dari Play Store. Itu peringatan bawaan Android, bukan tanda berkasnya
bermasalah. Aktifkan izinnya sekali, lalu pemasangan berjalan normal.

**Apakah aplikasi bisa dipakai tanpa login?**
Bisa untuk menonton dan menjelajah katalog. Login dibutuhkan untuk menyimpan koleksi, menyimpan
riwayat, dan berkomentar.

**Koleksi saya hilang setelah ganti perangkat?**
Coba **Profil → Sinkronkan ulang data akun** setelah masuk dengan akun yang sama.
